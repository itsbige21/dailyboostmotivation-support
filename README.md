# Daily Boost - Motivation Support

## FAQ
- Widget not showing? - Ensure added to home/lock screen. Restart phone if stuck.
- AI prompt rejected? - Avoid names, brands, or explicit content—rephrase.
- Premium not unlocking? - Check internet, restore purchases in Settings, or contact Apple Support.
- Notifications missing? - Enable in iOS Settings > DailyBoost > Allow Notifications.
= Data privacy? - App uses anonymous analytics only—no personal data collected.
